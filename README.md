# InfoSnity | Institutional Information Portal

A responsive React.js frontend for a centralized institutional information portal designed to support 300+ concurrent users with optimized performance and seamless API integration.

## 🎯 Overview

InfoSnity is an institutional information portal that provides a modern, user-friendly interface for accessing and managing institutional data. Built with a focus on performance optimization and parallel development through API-contract-first methodology.

## 🛠 Tech Stack

- **Frontend Framework**: React.js
- **Backend**: Node.js
- **Database**: PostgreSQL
- **Markup & Styling**: HTML5, CSS3
- **Design Approach**: Responsive Design
- **API Architecture**: REST APIs

## ✨ Key Features

- **Responsive Design**: Fully responsive interface supporting desktop, tablet, and mobile devices
- **High Concurrency Support**: Optimized to handle 300+ concurrent users simultaneously
- **Performance Optimized**: 40% improvement in data retrieval latency through query optimization and strategic indexing
- **API-Contract-First Development**: Enables parallel frontend-backend delivery with zero integration regressions
- **Modern UI/UX**: Clean and intuitive user interface for institutional information access

## 🚀 Quick Start

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/sandeep2811-dev/Infty-frontend.git

# Navigate to the project directory
cd Infty-frontend

# Install dependencies
npm install

# Start the development server
npm start
```

The application will open at `http://localhost:3000`

## 📦 Build for Production

```bash
npm run build
```

This creates an optimized production build in the `build` folder.
